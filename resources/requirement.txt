GitHub Commands
- git init                          Initialize new Repository
- git clone <repository-url>        Remote Repository to Local machine
- git status                        Status of current working directory
- git add <file>                    Adds file to staging area
- git commit -m "<commit-name>"     Commit staging area with message
- git push                          Push local machine to remote repository
- git fetch                         Updates downloads from remote repository
- git pull                          Pulls changes from remote repository to local machine
- git branch                        Lists all branches in remote repository
- git branch <branch-name>          Creates a new branch
- git checkout <branch-name>        Switches to a different branch
- git merge <branch-name>           Merge specified branch to current branch
- git reset --hard                  Reset to last commit
