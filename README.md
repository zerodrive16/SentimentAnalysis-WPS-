# 🚀 SentimentAnalysis
A tool for analyzing Text Content with AI Integration in Post, Comments from Reddit 
---

## 🔧 Prerequisites
- Python 3.12 or later
- pip (Python package manager)

## 📦 Installation
Follow these steps to set up the application on your Mac 

--- 

### 1. Clone the Repository 
Copy the Repository to a desired folder or your IDE workspace
```bash
https://github.com/zerodrive16/SentimentAnalysis-WPS-.git
```

### 2. Create a Virtual Environment
Run the following command to create a virtual environment in the project directory:
```bash
python -m venv <name>
```

### 3. Activate the Virtual Environment
Activate the Virtual Environment: 
```bash
source <name>/bin/activate
```

### 4. Installing packages
Install requirements.txt that includes all needed Packages
```bash
pip install -r requirements.txt
```

### 5. Starting the program
Start the Program to open the created Web Application
```bash
python manage.py runserver
```
---
